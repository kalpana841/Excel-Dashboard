This project focuses on analyzing sales data using SQL and Microsoft Excel to generate meaningful business insights and support data-driven decision-making.
The project begins with data cleaning and preparation, followed by storing and analyzing the data using SQL. SQL queries are used to retrieve, filter, aggregate, and analyze important business information such as sales, revenue, customers, products, and order performance.
After SQL analysis, the data is further analyzed in Excel using features such as Pivot Tables, Pivot Charts, formulas, and dashboards. The final analysis presents important KPIs and trends in an easy-to-understand visual format.
Key Objectives
Clean and prepare raw sales data.
Analyze sales data using SQL queries.
Calculate important business metrics such as total sales and revenue.
Identify sales trends and top-performing products/categories.
Analyze customer and order performance.
Create Pivot Tables and charts in Excel.
Build an interactive and easy-to-understand sales dashboard.
Generate actionable business insights from the data.
Tools & Technologies
SQL / SQL Server – Data storage, querying, filtering and analysis
Microsoft Excel – Data analysis, Pivot Tables, charts and dashboard
Data Analysis – KPI calculation and business insights
